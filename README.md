"The rails run submerged beneath two inches of calm water.
 The train travels only in one direction.

 Passengers carry paper tickets stamped with names
 they no longer answer to;
 their silhouettes dissolve gently against the dusk.

 Memory is not an archive of forms,
 but an echo left upon the surface before the crossing.

 Nothing is ever truly lost—
 it has merely learned to exist without a contour."
